# DARKVIWS — AI Video Studio

Interface inicial Cyberpunk para Windows, em Electron. O código inclui gerenciamento local de projetos e navegação. **Esta versão não gera vídeos nem vozes com IA**. O motor de IA será conectado futuramente.

## Instalador automático

A cada commit em main, o GitHub Actions executa **DARKVIWS Windows Installer** e disponibiliza em Artifacts o arquivo ZIP com o instalador `DARKVIWS-Setup-1.0.0.exe`. Baixe e execute o instalador. Não é necessário instalar Node.js no computador que utilizará o software.

A compilação usa GitHub Actions; não é hospedagem permanente para geração de vídeos.
